# PyCleaner Pro
PyCleaner Pro is a lightweight, open-source system optimization and privacy tool built entirely in Python. Inspired by CCleaner, it helps users reclaim valuable disk space, speed up their systems, and protect their digital privacy by safely removing junk files and temporary data.

System Junk Cleaner: Scans and removes temporary files, log files, and error reports left behind by the OS.

Recycle Bin & Clipboard Flush: Empties your system trash and clears the clipboard history with a single click.

Fast & Safe: Built-in safeguards ensure critical system files and active processes are never touched.

Modern GUI/CLI: Comes with a clean, user-friendly graphical interface.

# Safety & Privacy Disclaimer
PyCleaner Pro operates strictly locally. It does not collect, track, or upload any personal data or file histories. Always review the scan results before proceeding with a permanent deletion.
